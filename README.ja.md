# address-japan

日本の都道府県、市区町村、住所の全データをCSVファイルとしてダウンロードします。

## 要件
[Deno](https://deno.land/)

## 使用方法
```
$ mkdir data
$ deno run -A https://code4fukui.github.io/address-japan/downloadAll.js
```

## データ / API
出典: [アドレス・ベース・レジストリ（市区町村マスターデータ）](https://www.digital.go.jp/news/KgQ8ac8h/) [ベースレジストリ データカタログサイト](https://registry-catalog.registries.digital.go.jp/dataset/o1-000000_g2-000002) （2022年4月26日取得）
